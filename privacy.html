Kaijeh Stats privacy policy

Effective 31 October 2026

Kaijeh Stats is a private reporting tool used only by the owner of the Kaijeh shop. It reads the shop's own performance figures from Pinterest and Etsy and turns them into a weekly report for the owner. It is not offered to anyone else.

Who runs it

Kaijeh Stats is operated by Aashima Taneja, owner of the Kaijeh shop, Mumbai, India.

What data it reads

  • From Pinterest: analytics for the Kaijeh Pinterest account only, such as impressions, saves, Pin clicks and outbound clicks, plus basic information about its own Pins and boards.
  • From Etsy: the Kaijeh shop's own listings, orders and reviews, as provided by Etsy's official API.

It does not read data about other Pinterest users, other Pinterest accounts or other Etsy shops.

What it stores

  • Daily totals and per-listing figures, kept in a private repository that only the owner can access.
  • For Etsy orders: the order number, date, amount, discount, refund, buyer country and the listings bought. Buyer names, email addresses, postal addresses and user IDs are not stored.
  • For Etsy reviews: the date, star rating and review text, which Etsy already shows publicly. Reviewer IDs are not stored.
  • The access tokens issued by Pinterest and Etsy, kept in a configuration file on the owner's private server and never shared or published.

How it is used and shared

The data is used only to produce the owner's own performance report. It is not sold, rented, shared with third parties or used for advertising.

Security and retention

Access to the server and repository is limited to the owner. Data is kept for as long as it is useful for the shop's reporting and can be deleted at any time.

Stopping access

The owner can stop Kaijeh Stats at any time by removing its access in the Pinterest and Etsy account settings. Pinterest and Etsy then stop providing data, and the stored data can be deleted.

Contact

Questions about this policy can be sent through the Kaijeh shop on Etsy: kaijeh.etsy.com.
